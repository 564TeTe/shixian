# 实验教学项目管理系统 · 静态原型

双击 `index.html`，使用 Chrome、Edge 或 Firefox 等现代浏览器打开即可。无需安装依赖、构建、启动后端或连接网络。

也可在项目根目录执行 `python -m http.server 8090 --directory static-front`，访问 `http://localhost:8090`。

## 功能范围

依据项目 README、`front/src/views/teaching/` 和需求说明制作，保留当前实验教学功能：

| 页面 | 可体验功能 |
| --- | --- |
| 教学概览 | 学期概览、任务/项目/实验室/人时统计、教学分布、待办入口 |
| 课程与课表 | 搜索、教学任务、逐周课表、课程详情；管理员可进入课表导入 |
| 实验项目 | 教师维护本人当前学期项目；管理员只可筛选和查看详情 |
| 学年学期 | 当前与历史学期、归档状态、自动生成规则展示 |
| 实验室 | 实验室卡片、详情，资料只读 |
| 教师账号 | 管理员查看教师资料、临时账号标记及授课任务数，可演示重置教师密码 |
| 导入中心 | 管理员导入课表：文件选择、字段示例、固定预览、批次详情、疑似重复核对 |
| 统计报表 | 仅管理员：实验室使用统计、项目清单、人时图表、CSV 导出 |
| 智能查询 | 两端均可使用：提示词、预设回答、结果表格、示例 SQL、CSV 导出 |
| 账号与安全 | 角色资料、密码校验演示、退出/登录页 |

右上角切换 **管理员端 / 教师端 · 陈老师**，或从登录页选择角色：

- 管理员端：可导入课表、查看教师创建的项目、查看统计报表、使用智能查询及重置教师密码。重置密码提供确认与成功弹窗，仅演示流程。没有实验项目新增、编辑、删除、导入或复制入口，也不提供手动修改基础资料的入口。
- 教师端：仅可查看本人授课任务，新增、编辑、删除、导入或复制本人当前学期的实验项目；可使用智能查询查看本人教学数据。没有统计报表、教师资料管理或课表导入入口。
- 历史学期的项目对两端均为只读；教师可切换到当前学期，从同课程历史任务复制项目。
- 页面、点击操作与表单提交均校验演示角色和任务归属；切换角色或学期时关闭未提交弹窗。

项目编号统一为 **实验室编号 + 三位顺序后缀**，例如 `36-606-001`。根据目标教学任务所属实验室自动生成，编号只读；新增、导入和历史复制共用编号规则。同实验室编辑保留原编号，变更为不同实验室时重新生成编号。后缀超过 `999` 时拒绝操作，批量复制不会部分写入。

## 演示边界

- 所有数据都是虚构示例，并非数据库真实记录；新增、编辑和删除仅作用于内存，刷新即可还原。没有 `fetch`、XHR、外部字体或 CDN 请求。
- 导入只展示所选文件名，不读取内容、不上传文件。确认导入后生成固定演示批次；项目导入生成一条固定示例项目。批次核对只更新演示状态。
- 模板字段示例和报表导出为带 UTF-8 BOM 的 `.csv` 文件，可使用 Excel 打开。没有将 CSV 伪装为 `.xlsx`，也没有引入 Excel 解析依赖。
- AI 仅支持页面上的三个预设问题。其他问题提示选择示例，不调用模型或执行 SQL。
- 登录不需要真实账号和密码。密码表单只做校验，不存储输入，不修改真实账号；这不是安全鉴权实现。
- 教学人时根据示例逐周排课学时和选课人数计算。未采集的项目实际参与人数不以选课人数替代。
- 页面布局适配桌面和手机，提供键盘焦点、原生对话框、无障碍表单名称和动态消息提示。

## 文件

- `index.html`：直接打开的入口。
- `styles.css`：独立样式及响应式布局。
- `data.js`：演示数据。
- `app.js`：页面与交互，无第三方运行依赖。
- `favicon.svg`：本地图标。
- `smoke-test.cjs`：浏览器冒烟验证，不是页面运行依赖。

## 验证

使用 Node.js 22+ 与本机 Chrome/Edge，在项目根目录执行：

```powershell
node --check static-front/app.js
node --check static-front/data.js
node static-front/smoke-test.cjs
```

浏览器检查直接通过 `file://` 打开入口，覆盖页面访问、筛选、项目维护、历史复制、角色范围、只读限制、导入核对、CSV 导出、智能查询和手机布局。截图与下载文件保存在系统临时目录，路径在测试输出中显示。

页面为原生 JavaScript，无 TypeScript 编译或构建步骤。可复用现有前端 ESLint 与 Babel 解析器进行静态检查。

现有 `front`、`back`、`database` 和 `static_front` 均不受影响。
