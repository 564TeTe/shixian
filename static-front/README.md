# 实验教学项目管理系统 · 独立前端

`static-front` 是无需构建步骤的原生 HTML/CSS/JavaScript 前端。打开页面首先进入登录界面；登录成功后，页面通过 `api-client.js` 使用 Spring Boot Token API 读取和写入 MySQL 数据。未登录访问业务页会自动返回登录页。

## 启动

后端默认地址为 `http://localhost:8080/springboote51e2`，静态前端建议通过 HTTP 启动：

```powershell
cd C:\Users\zhaom\IdeaProjects\shixian\static-front
npm start
```

访问 `http://localhost:8090`。后端 CORS 已允许 `localhost:8090` 和 `127.0.0.1:8090`。

可以在加载页面前覆盖后端地址：

```html
<script>window.STATIC_FRONT_API_BASE = 'http://localhost:8080/springboote51e2';</script>
```

开发数据库管理员账号为 `admin / Teaching2026!`。教师账号由管理员创建或重置，登录时选择“教师端”。

## 数据库连接范围

| 页面 | 已接入的后端能力 |
| --- | --- |
| 登录 | 管理员／教师分角色登录、数据库账号校验、Token 保存与退出 |
| 教学概览 | 后端统计、当前学期、教学任务汇总、数据库校验提醒 |
| 课程与课表 | 教学任务分页查询、逐周真实排课详情、管理员创建当前学期任务 |
| 实验项目 | 教师查询、新增、编辑、删除、Excel 导入、从同课程历史任务复制 |
| 学年学期 | 数据库学期记录、当前开放学期补齐 |
| 实验室 | 数据库实验室列表；管理员新增、编辑、删除 |
| 教师账号 | 数据库教师列表；管理员新增、编辑、删除、重置一次性密码 |
| 导入中心 | 课表／教师／实验室 Excel 上传、模板下载、导入批次和逐行核对 |
| 统计报表 | 后端实验室学时／人时聚合、项目清单与 Excel 导出 |
| 智能查询 | 后端 AI 配置状态、自然语言查询、结果 SQL 与结果表 |
| 账号与安全 | 后端原密码校验、修改密码、退出登录 |

登录后所有业务页均从 API 获取数据。退出登录、Token 过期或后端返回未登录状态时，前端会清理本地会话并回到登录页。

## 数据与权限

- 管理员可创建当前学期任务，维护教师与实验室资料，导入课表并查看统计报表。
- 教师只能访问本人授课任务；当前开放学期可维护本人实验项目，历史学期只读并可复制项目。
- 管理员在实验项目中保持只读审计视角，不提供项目新增、编辑、删除、导入或复制入口。
- 项目导入与课表导入会在后端完整校验；课表疑似重复行保留在导入中心，由管理员逐行确认。
- 智能查询是否可用取决于后端 AI 环境变量；未配置时前端显示后端返回的真实状态，不伪造查询结果。

## 文件

- `index.html`：页面入口。
- `api-client.js`：Token、登录、分页、上传、下载和字段适配。
- `app.js`：页面渲染与真实 API 交互。
- `styles.css`：响应式界面样式。
- `data.js`：保留的本地示例数据结构；当前登录模式下不作为业务数据源。
- `server.js`：无依赖静态文件服务器。

## 验证

```powershell
npm run check
npm test
```

`npm test` 使用本机 Chrome 或 Edge 验证未登录默认进入登录页、业务页拦截和手机宽度。真实账号登录与数据库联调建议在 `http://localhost:8090` 进行，因为浏览器会对 `file://` 跨域请求执行更严格的限制。
