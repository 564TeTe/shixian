# 英文表名、字段名与中文注释

新版 `T132.sql` 共 13 张表、117 个字段，均有数据库级中文 COMMENT。教师与实验室相关名称已改为英文；其余原有英文名称保持不变。`token.token` 的注释修正为“登录令牌”。

## 已经导入过旧 SQL

停止后端并备份数据库。在项目根目录启动 MySQL 客户端，执行：

```sql
USE t132;
SOURCE database/004_english_schema.sql;
```

该脚本保留数据、主键、外键、默认值、校验约束和账号密码，同时更新令牌中的账号表名。执行前检查预期的表和字段，名称冲突或结构不完整时明确报错；允许成功后重复执行。MySQL DDL 会隐式提交，异常中断后先排查报错，再重新执行，不依赖事务回滚恢复结构。适用于旧版 T132，或已完成 001、002 的教学库。

迁移后运行 `.\start-teaching.ps1 -Build -Restart`，使后端使用新版数据库引用。不要重跑 `T132.sql`，其中的 DROP TABLE 会删除现有数据。新库直接导入新版 `T132.sql`、`003_teaching_seed.sql`，无需运行 001、002、004。

使用 AI 查询且只读账号按表授权时，需要由管理员为原账号补授 `laboratory` 的 SELECT 权限。表重命名不会自动迁移旧表级授权；不要给只读账号授予 `teacher`、`users`、`token` 或写入权限。

## 查看注释

数据库工具中刷新结构，重新打开表或 ER 图；是否直接显示 COMMENT 取决于工具的注释显示选项。可在 MySQL 中核对：

```sql
SHOW FULL COLUMNS FROM teacher;
SHOW FULL COLUMNS FROM laboratory;
SELECT TABLE_NAME, TABLE_COMMENT
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = DATABASE();
SELECT TABLE_NAME, COLUMN_NAME, COLUMN_COMMENT
FROM information_schema.COLUMNS
WHERE TABLE_SCHEMA = DATABASE()
ORDER BY TABLE_NAME, ORDINAL_POSITION;
```

## 验证脚本

`python tools/database/verify_english_schema.py --backend-tests` 在独立临时 MySQL 库检查新库导入、旧名迁移、117 个字段的注释、全部行数据与密码保留、外键和索引一致、重复迁移，并执行后端数据库测试。需设置 `MYSQL_PWD`，安装 `tools/database/bootstrap-requirements.txt`，并提供 MySQL、Maven。`--legacy-ref <旧提交号>` 可直接以该版本的 T132 和 003 作为旧库基线。脚本结束后删除自身测试库，不修改业务库。
