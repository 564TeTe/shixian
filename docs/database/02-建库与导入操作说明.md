## 开始使用

1. 运行项目根目录 `start-teaching.ps1`，访问 http://localhost:8081 。
2. 管理员账号 admin，密码见本机 `database/generated/teaching-accounts.local.json`。
3. 在教师与实验室页面核实临时工号、负责人和设备数。
4. 在“课程与课表”创建当前学期任务，或通过导入中心上传当前课表。
5. 为任务录入真实实验项目；在统计报表按学年／学期查询、导出。

教师只能访问参与的任务及项目，不能管理账号、上传整体课表或使用管理员自然语言数据库查询。

## 新机器初始化

安装 MySQL 8、Java、Maven、Node.js、Python。MySQL 客户端内：

```sql
CREATE DATABASE t132 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE t132;
SOURCE D:/STUDY/iahfbiwabidubIO/T132.sql;
```

T132.sql 已改为纯结构，无 DROP DATABASE 或演示 INSERT。已有旧库使用 001、002 增量脚本，不重复导入纯结构。

将 MySQL bin 加入 PATH，在进程环境中配置 MYSQL_PWD，然后：

```powershell
python -m pip install -r tools/database/bootstrap-requirements.txt
python tools/database/bootstrap_teaching.py --workbook '<真实课表.xlsx路径>' --reset-legacy-data
```

这个命令会清理已有业务数据，仅用于明确重新初始化时。解析、完整备份成功后才开始事务清理，失败回滚；连接参数支持 --host、--port、--user、--database。日常使用网页导入，不重跑清理。

## 数据口径

- TMP 是临时账号，不是学校工号；79 个不同姓名仍需核实人员身份及同名情况。
- 五组身份疑点源行 43/44、45/46、73/74、81/82、221/222 分别保留，不擅自合并。
- 11 个任务计划与排课学时不一致；报表按排课学时计，人时为每条排课学时乘任务选课人数，避免多教师／多项目重复累计。
- 202 行教学班人数与选课人数不同、9 行专业缺失，原值保留。选做项目实际参与人数不能由课程人数推定。
- 项目模板“示例”不作为正式教学内容；学科代码0809保留前导零。
- 相同文件不会重复生成；异文件疑似相同任务需逐行核对，确认独立后生成，不覆盖旧任务。
