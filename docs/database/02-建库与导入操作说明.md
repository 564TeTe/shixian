## 检查与修正

已通过 12 项单元测试，以及 MySQL 8.0.41 集成验证。验证覆盖首次/重复建表、缺失约束恢复、非法学年/学期/设备数拒绝、悬空外键拒绝、教师关联防重复、学科代码前导零保存、项目人数校验、人时数计算、中文 JSON 保存、重复导入。

实际查出并修正的问题：

1. 原 SQL 的自复制 CHECK 引用自增 ID，MySQL 实测报错 3818。已移除非法约束，复制来源外键保留；后续复制接口需禁止自引用和循环引用。
2. 课表第 176 行日期末尾有空格，原解析器误报。现校验时去空白、原始字段原样保存。
3. 非空工作表首行缺表头时，现明确报错，防止静默漏表。
4. Excel 纯时间/时长类型可序列化为 JSON；异常行保持错误标记，不阻断整批暂存。
5. 实验室新增列与约束分别检查，中断后可以重跑补齐约束。

同一课表连续导入两次仍为 1 个批次、255 行；已审核状态不会被覆盖。独立审查复验了两项解析器修复。所有模拟测试数据仅写入临时库。

以下 PowerShell 命令在项目根目录执行。依赖为 `tools/database/requirements.txt` 中的 openpyxl。

手动重跑已验证脚本时，先登录现有开发库：

```powershell
mysql --host=127.0.0.1 --port=3306 --user=root -p --default-character-set=utf8mb4 t132
```

在 MySQL 提示符执行：

```sql
SOURCE D:/STUDY/iahfbiwabidubIO/database/001_teaching_foundation.sql;
SOURCE D:/STUDY/iahfbiwabidubIO/database/generated/2025-2026-staging.sql;

```

不要使用原始 `T132.sql` 代替增量脚本，它包含 DROP DATABASE 和演示数据。

集成验证工具默认只读 `t132` 两张旧表的结构，所有测试写入自己新建的临时库。支持 `--host`、`--port`、`--user`、`--source-database`、`--mysql` 参数，密码从调用进程的 `MYSQL_PWD` 环境变量继承。示例调用为 `python tools/database/verify_mysql.py --workbook <课表路径> --report <报告路径>`，需要调用环境已配置连接凭据。

同一文件以 SHA-256 识别；内容改变形成新批次，不自动覆盖旧任务。解析器版本写入批次，升级后不会静默重写旧批次。需要重处理时应另行设计审核流程。
