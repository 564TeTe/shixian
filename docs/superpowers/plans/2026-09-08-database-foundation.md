# 教学数据库基础 Implementation Plan

> **For agentic workers:** 按本计划逐项执行；本次在当前会话内实施，独立审阅设计与实现，不并行修改同一文件。

**Goal:** 建立可验证的 MySQL 教学业务表，提供 Excel 暂存导入和数据疑点报告，保留现有业务数据。

**Architecture:** 复用旧教师与实验室表，新增学年、学期、课程、教学任务、多教师关联、排课、实验项目；新增导入批次和原始行暂存。先在隔离验证库运行，数据库连接使用现有本机配置，仅新增结构与暂存数据，不重置原库、不把样例项目和不明教师身份正式入库。

**Tech Stack:** MySQL 8、Python/openpyxl、标准库 unittest；本阶段不修改 Java/Vue 业务行为。

## 文件分工

- `database/001_teaching_foundation.sql`：新增业务与导入表、必要的基础表扩展。
- `tools/database/schedule_import.py`：严格解析课表、生成校验报告与暂存导入 SQL，不连接数据库。
- `tools/database/tests/test_schedule_import.py`：周次、节次、地点配对、数值校验、疑点及重复文件导入语义测试。
- `docs/database/02-建库与导入操作说明.md`：实际执行方式、验证证据、限制与后续步骤。
- `docs/database/reports/`：不含密码的数据质量统计，保留定位行号。

## 验收口径

1. 既有教师、实验室及其他业务记录保留，不执行原始 `T132.sql`。
2. 255 行完整暂存，同一文件重复运行不产生第二个批次或重复行。
3. 435 个排课原始片段可解析；保留 11 行学时不一致、202 行人数差异、9 行专业缺失、5 组任务身份疑点。
4. 课表第 252 行按选课人数口径：36-506 为 376 人时，36-508 为 188 人时。
5. 暂存成功不宣称正式教学业务已上线；教师映射、实际项目数据、正式报表口径与页面开发为后续阶段。
